# عالم الأبطال التعليمي

> تعلّم، العب، واكتشف!

منصة ألعاب تعليمية عربية تفاعلية لطلاب الصفوف الأول والثاني والثالث الأساسي، صُممت ليستخدمها المعلم داخل الغرفة الصفية على الحاسوب أو الشاشة الذكية. تعمل بالكامل دون إنترنت بعد التحميل ودون أي خدمة مدفوعة، وتحفظ البيانات محليًا على جهاز المعلم.

## التشغيل

```bash
npm install
npm run dev          # خادم التطوير على http://localhost:3000
npm run build && npm start   # نسخة الإنتاج
```

## نسخة ملف واحد (بدون خادم)

```bash
npm run build:standalone   # يُنتج dist-standalone/index.html يعمل وحده
node scripts/make-artifact.mjs dist-standalone/index.html heroes-world.html   # نسخة للنشر على claude.ai
```

## الاختبارات

```bash
npm run lint         # فحص الأنواع (TypeScript)
npm test             # اختبارات الوحدات (Vitest)
npm run build && npm run test:e2e   # اختبارات المتصفح (Playwright)
```

### ملاحظات ألعاب الرياضيات

- كل لعبة تولّد مهامها محليًا بمولّد مختبَر (`src/lib/math/games.ts`)، وبثلاثة مستويات وعدد مهام ووضع تعليمي/اختباري.
- **النقود:** فئات المسكوكات من قائمة البنك المركزي الأردني (cbj.gov.jo › المسكوكات). تستخدم اللعبة القرش و٥ و١٠ قروش وربع الدينار ونصفه والدينار، برسومات مبسطة تُظهر الفئة والشكل (ربع الدينار سباعي) ولونًا قريبًا من المعدن، وليست نسخًا لتصميم القطع.

### فهرس المنهاج

`src/content/curriculum/grade1-math.ts`: ١٢ وحدة و٦٦ درسًا في فصلين، منقولة من فهرس موقع إقرأ
(https://www.iqrra.com/manhaj/grade-1-mathematics) الذي يذكر أنه وفق المركز الوطني لتطوير المناهج.
**لم تُطابَق مع نسخة الكتاب الرسمية** لأن nccd.gov.jo لم يكن متاحًا من بيئة التطوير، وتظهر حالة التحقق في الواجهة.
يستطيع المعلم تصحيح عناوين الدروس من صفحة «المنهاج والدروس».

### محرك تحضير الحصص

`src/lib/lessons/engine.ts`: قوالب تعليمية وقواعد ومولّدات أسئلة محلية (ليس ذكاءً اصطناعيًا ولا يحتاج إنترنت).
أسئلة التحدي الختامي لا تتكرر في اللعبة الرئيسية، وكل الأعداد ضمن النطاق المختار.

## البنية

```
src/
  app/(dash)/        صفحات لوحة التحكم
  app/play/          وضع الحصة الصفية
  components/        واجهة مشتركة، الشخصيات، محرر الأسئلة، معالج الإنشاء
  games/             الألعاب (كل لعبة تُحمَّل عند الحاجة فقط)
    shared/          المؤقت، لوحة الأسئلة، التغذية الراجعة، ملء الشاشة
  lib/               الأنواع، الأسئلة والتحقق، النقاط، العجلة، الصوت، التخزين، العربية
  lib/ai/            نقطة توسعة مولّد الألعاب الذكي (يعمل حاليًا دون إنترنت)
  content/seed.ts    المحتوى التجريبي
  store/             حالة التطبيق (Zustand)
tests/unit, tests/e2e
```

## ملاحظات مهمة

- **المحتوى التجريبي** مكتوب ليناسب أعمار الطلاب، لكنه **غير مُطابَق رسميًا** مع المنهاج الأردني أو أي منهاج معتمد؛ يُرجى مراجعته وتكييفه.
- **البيانات محلية**: تُحفظ في IndexedDB على المتصفح نفسه. حذف بيانات المتصفح يحذفها؛ استخدم «تصدير نسخة احتياطية» من الإعدادات.
- **الأصوات** مولَّدة برمجيًا عبر Web Audio API (بلا ملفات خارجية). العبارات التشجيعية تظهر مكتوبة دائمًا، ويمكن نطقها بصوت عربي من الجهاز إن توفر.
- **الشخصيات والرسوم** أصلية بالكامل (SVG ومجسمات ثلاثية الأبعاد بسيطة).
- لا تجمع المنصة أي بيانات شخصية عن الطلاب.
