# دليل التثبيت المختصر — عالم الأبطال التعليمي 1.0.0

**المتطلبات:** Windows 10 أو Windows 11 (64-بت)، ونحو 500 م.ب مساحة. لا يحتاج البرنامج إنترنت للعمل.

## التثبيت (مُوصى به)

1. شغّل `Heroes-World-Setup-1.0.0.exe`.
2. إن ظهر تحذير SmartScreen: «مزيد من المعلومات» ← «تشغيل على أي حال» (البرنامج غير موقّع رقميًا بعد).
3. اختر مجلد التثبيت أو اترك الافتراضي، ثم «تثبيت». لا يحتاج صلاحيات المدير.
4. افتح البرنامج من قائمة ابدأ أو من سطح المكتب: «عالم الأبطال التعليمي».

## النسخة المحمولة (USB)

- انسخ `Heroes-World-Portable-1.0.0.exe` إلى الذاكرة وشغّله.
- تُحفظ البيانات في مجلد `HeroesWorld-Data` بجانبه. انقل المجلد مع البرنامج.
- هذه النسخة لا تُحدَّث تلقائيًا.

## التحديثات

- **الفحص:** يفحص البرنامج عند التشغيل إن كان الإنترنت متاحًا، أو يدويًا من «الإعدادات ← التحديثات ← فحص التحديثات الآن».
- **التثبيت:** «تنزيل التحديث» ثم «إعادة التشغيل وتثبيت التحديث». يُحفظ كل شيء قبل الإغلاق، ثم يُفتح البرنامج بالإصدار الجديد.

## أين بياناتي؟

- **البيانات:** `%APPDATA%\HeroesWorld`، ويمكن فتح المجلد من «الإعدادات ← البيانات».
- **النسخ الاحتياطية:**
  - `backups\heroes-world-auto-*.json`: آخر 10 نسخ تلقائية.
  - `backups\before-<الإصدار>-*`: نسخة قبل كل ترقية.
- **الإزالة:** إعدادات Windows ← التطبيقات ← «عالم الأبطال التعليمي (Heroes World)» ← إزالة. **البيانات تبقى**؛ احذف المجلد يدويًا فقط إن أردت مسحها نهائيًا.

## التحقق من سلامة الملفات

```powershell
Get-FileHash .\Heroes-World-Setup-1.0.0.exe -Algorithm SHA256
```

قارن الناتج بالسطر المقابل في `SHA256SUMS.txt`.
