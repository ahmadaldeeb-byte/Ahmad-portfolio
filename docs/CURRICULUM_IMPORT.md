# استيراد المناهج من كتب PDF

الهدف: إضافة كتاب مدرسي كامل إلى «عالم الأبطال» بلا برمجة يدوية للدروس والأسئلة.

```
كتاب PDF ──(Claude Code + المهارة textbook-to-curriculum)──▶ ملف منهج JSON ──(📚 استيراد منهج)──▶ المنصة
```

- معالجة الكتاب تتم **خارج التطبيق**. التطبيق لا يتصل بأي خدمة ذكاء اصطناعي، ولا يحتوي خادمًا لمعالجة PDF.
- ملف المنهج JSON عادي، فيعمل في الويب وويندوز وأي إصدار مستقبلي (مثل iOS).

## ١. من PDF إلى JSON (في Claude Code)

افتح المشروع في Claude Code واكتب مثلًا:

> حوّل الكتاب books/math-g1-s1.pdf إلى ملف منهج باستخدام مهارة textbook-to-curriculum

المهارة في `.claude/skills/textbook-to-curriculum/SKILL.md`، وتتّبع هذه الخطوات:
1. تقرأ صفحات الفهرس.
2. تنقل الوحدات والدروس **بعناوينها الأصلية كما هي** (لا تخترع وحدة ولا درسًا).
3. تأخذ تمارين كل درس مع رقم الصفحة.
4. تضيف أسئلة مولّدة **معلّمة بوضوح**.
5. تتحقق من الإجابات.
6. تختار قوالب الألعاب الموجودة.
7. تكتب الملف وتفحصه.

إذا لم يكن موقع الكتب الرسمي متاحًا من بيئة Claude Code: عدّل `curricula/fetch-request.json` وادفعه، فيُنزّل سير العمل «Fetch textbook PDF» الكتابَ ملحقًا (Artifact) لبضعة أيام.

**الفحص من الطرفية** (بقواعد التطبيق نفسها):

```bash
node scripts/curriculum/check.mjs curricula/jo-g1-math-s1.json
```

## الكتب المدمجة في المنصة

- كتابا «الرياضيات» و«العربية لغتي» للصف الأول (الفصل الأول) مدمجان في المنصة من `curricula/` عبر `src/content/catalog.ts`.
- يظهران عند فتح المنصة دون استيراد: في «المنهاج والدروس»، و«✨ حضّر حصتك»، و«بنك الأسئلة»، ومع ألعاب كل درس.
- لكل درس: 📖 شرح الدرس (أهداف، شرح للمعلم، أمثلة، نشاط تمهيدي)، 🎮 ألعاب جاهزة، ✨ حصة جاهزة من ١٥ دقيقة، ✏️ تعديل المحتوى.
- **المحتوى الأصلي لا يتغيّر:**
  - تعديل الحصة الجاهزة يحفظ نسخة خاصة بالمعلم في «تحضير الحصص».
  - تخصيص لعبة يحفظ نسخة في «ألعابي المحفوظة» مرتبطة بالدرس.
  - أسئلة الكتاب تُضاف إلى بنك الأسئلة مرة واحدة فقط. تعديلها أو حذفها يبقى كما هو، ولا تتكرر عند إعادة التشغيل.
- استيراد ملف كتاب مدمج يُرفض برسالة «مدمج في المنصة».

## ٢. الاستيراد في المنصة

1. **📚 استيراد منهج** ← «اختيار ملف منهج».
2. **فحص فوري:**
   - الأخطاء تمنع الاستيراد: حقل ناقص، معرّف مكرر، إجابة خاطئة، قالب غير موجود.
   - التنبيهات تُعرض فقط، مثل درس أسئلته لا تكفي لأي لعبة.
3. **معاينة قابلة للتعديل:**
   - عناوين الوحدات والدروس.
   - حذف درس.
   - تعديل نص السؤال وخياراته والإجابة الصحيحة، أو حذفه.
   - تشغيل قوالب الألعاب لكل درس أو إيقافها.

   كل سؤال يحمل شارة **📘 من الكتاب ص…** أو **✨ مولّد — راجعه**.
4. **«استيراد»:**
   - تُضاف الأسئلة إلى بنك الأسئلة.
   - تُنشأ الألعاب في «ألعابي المحفوظة».
   - يظهر الكتاب في «المنهاج والدروس» (اختيار الكتاب إن وُجد أكثر من كتاب للصف والمادة)، ولكل درس ألعابه.

**القواعد الثابتة:**
- **لا تكرار:** يُرفض الكتاب نفسه مرة ثانية (ببصمة ملف PDF أو بعناوين الدروس)، وتُرفض أي محاولة بنفس المعرّف.
- **لا مساس بالموجود:** الاستيراد يضيف سجلات جديدة فقط. ألعابك وأسئلتك وحصصك لا تتغير.
- **التراجع:** حذف المنهج المستورد يحذف ما أنشأه هو فقط.
- **النسخ الاحتياطي:** النسخة الاحتياطية (الإعدادات ← تصدير) تحمل المناهج المستوردة وأسئلتها وألعابها، والاستعادة تعيدها.

## ٣. كيف تُبنى الألعاب

- **اللعبة الجاهزة:** لكل درس، كل قالب مطلوب يصبح لعبة جاهزة مرتبطة بالدرس (`lessonId`):
  - ألعاب الرياضيات المولّدة (الصاروخ، الجزيرة، المصنع…) تولّد مهامها بالمستوى المطلوب في مادة الرياضيات.
  - ألعاب الأسئلة (المسابقة، العجلة، البالونات، الذاكرة، صانع الكلمات…) تأخذ أسئلة الدرس المناسبة لنوعها.
- **اختيار تلقائي:** إن لم يحدد الملف قوالب، يختار التطبيق:
  - «من بطل المعرفة؟» لثلاثة أسئلة اختيار أو أكثر.
  - «ذاكرة الأبطال» لأسئلة المطابقة.
  - «صانع الكلمات» لسؤالَي ترتيب أو أكثر في العربية والإنجليزية.
- **الرفض:** كل لعبة تمر بفحص الألعاب نفسه في التطبيق. اللعبة التي لا تصلح تُترك مع تنبيه في المعاينة.

## ٤. صيغة الملف

- **الأنواع:** `src/lib/curriculum/schema.ts`.
- **مخطط JSON Schema:** `docs/curriculum.schema.json`.
- **مثال صغير:** `tests/fixtures/curriculum-sample.json`.
- **مثال حقيقي:** `curricula/`.

| الحقل | المعنى |
|---|---|
| `curriculum.id` | معرّف ثابت، مثل `jo-g1-math-s1-2022` |
| `grade`, `subject`, `semester` | الصف (1–3)، المادة (`arabic`/`math`/`science`/`english`)، الفصل (1/2) |
| `textbook` | العنوان، الناشر، الطبعة، ISBN، عدد الصفحات، `sha256` لملف PDF |
| `units[].lessons[]` | الوحدات والدروس بعناوين الكتاب ونطاق صفحاتها |
| `questions[].origin` | `textbook` (من الكتاب، مع `page`) أو `generated` (مولّد) |
| `questions[].kind` | `mcq` / `truefalse` / `arithmetic` / `order` / `match` (أنواع بنك الأسئلة نفسها) |
| `games[]` | `template` (قالب لعبة موجود)، `level` (1–3)، `count` |
| `guide` | دليل المعلم: `objectives`، `explanation`، `examples`، `warmup` (اقتراحات من المنصة) |
