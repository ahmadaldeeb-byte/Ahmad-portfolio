# عالم الأبطال — الإصدارات الثلاثة

مصدر واحد (Next.js + React) يبني **مجلدًا ثابتًا واحدًا** `out/`، ومنه تخرج الإصدارات الثلاثة:

| الإصدار | الملف | أين تُحفظ بيانات المعلم |
|---|---|---|
| المحمولة (USB) | `HeroesWorld-Portable.exe` | مجلد `HeroesWorld-Data` بجانب البرنامج على الذاكرة |
| المثبّتة | `HeroesWorld-Setup.exe` | `%APPDATA%\HeroesWorld` (تبقى بعد إلغاء التثبيت) |
| الويب | محتوى `out/` على أي استضافة HTTPS | تخزين المتصفح (IndexedDB) |

نسخ احتياطية تلقائية: في نسختي ويندوز يكتب التطبيق ملف JSON في `backups\` عند الفتح، وبعد كل تغيير، وقبل الإغلاق (آخر ١٠ نسخ).
إذا فُتح التطبيق وتخزينه فارغ وفي المجلد نسخة تلقائية، يعرض استعادتها.

## البناء

```bash
npm ci
npm run build            # out/ (الويب) + out/sw.js للعمل دون إنترنت
npm run dist:win         # dist-desktop/HeroesWorld-Portable.exe و HeroesWorld-Setup.exe
```

- `dist:win` يعمل على ويندوز مباشرة، وعلى لينكس مع Wine (يحتاجه مُنشئ المثبّت NSIS).
- الملفات غير موقّعة رقميًا، فيظهر تحذير SmartScreen: «مزيد من المعلومات» ← «التشغيل على أي حال». إزالته تحتاج شهادة توقيع (Code Signing) مدفوعة.
- **بناء ويندوز على GitHub:** سير العمل `.github/workflows/windows-release.yml` يعمل على Windows Server 2022 و2025، ويشغّل الاختبارات، ويبني الملفين ويختبرهما (تشغيل، تثبيت صامت، إلغاء تثبيت مع بقاء البيانات)، ثم يرفعهما في صفحة التشغيل ← Artifacts.

## التصميم التقني

- `next.config.ts`: ‏`output: "export"` و`trailingSlash: true`. لا يوجد كود خادم.
- `desktop/main.cjs` (Electron):
  - يقدّم `out/` عبر بروتوكول خاص `app://heroes` (أصل ثابت وآمن، فيعمل IndexedDB والمسارات كما في الويب).
  - يمنع أي طلب شبكة خارجي، ويفتح الروابط الخارجية في المتصفح.
  - يقفل التكبير باللمس ولوحة المفاتيح، وF11 لملء الشاشة، ويمنع تشغيل نسختين معًا.
  - يسمح برسوم WebGL البرمجية على الأجهزة التي حُظر فيها كرت الشاشة.
- `desktop/preload.cjs`: جسر صغير `window.heroesDesktop` (حفظ ملف، نسخة تلقائية، فتح مجلد البيانات). الصفحة لا تصل إلى Node.js.
- `src/lib/backup.ts`: صيغة النسخ الاحتياطية الإصدار ٢ (انظر أدناه).
- `src/lib/datastore.ts`: نقطة اختيار مخزن البيانات. اليوم: IndexedDB المحلي. لاحقًا: حسابات المعلمين بمزامنة سحابية بنفس الواجهة.
- `src/components/DesktopSync.tsx`: النسخ التلقائية وعرض الاستعادة (في ويندوز فقط).
- `src/components/SafeCanvas.tsx`: إن لم يتوفر WebGL تُستبدل الصورة ثلاثية الأبعاد بملاحظة، وتستمر اللعبة.
- الويب: `out/sw.js` يُولَّد بعد البناء (`scripts/build-sw.mjs`) ويخزّن الإصدار كله للعمل دون إنترنت بعد أول زيارة. `deploy/web/` فيه إعدادات nginx و`_headers`.

## صيغة النسخة الاحتياطية (الإصدار ٢)

```json
{
  "app": "heroes-world", "kind": "backup", "version": 2,
  "exportedAt": 1761300000000, "appVersion": "1.0.0", "platform": "web | desktop | portable",
  "counts": { "games": 3, "questions": 120, "results": 9, "lessons": 2 },
  "games": [], "questions": [], "results": [], "lessons": [],
  "settings": { "volume": 0.7, "numerals": "hindi" },
  "curriculumTitles": { "g1m-u1-l1": "…" }
}
```

- **التوافق:**
  - يقرأ الإصدارَ ١ (بدون `kind` والإعدادات والعناوين).
  - يحتفظ بترتيب حقول الإصدار ١، فالنسخ القديمة من التطبيق تقرأ ألعاب الملف الجديد وأسئلته.
  - إن جاء الملف من إصدار أحدث، تُستعاد الحقول المعروفة فقط مع تنبيه.
- **التحقق:** يُفحص كل سجل، وتُتجاهل السجلات التالفة مع إبلاغ المعلم.
- **طريقتا الاستعادة:**
  - «دمج»: لا يحذف شيئًا، والسجل ذو المعرّف نفسه يُستبدل.
  - «استبدال»: تُحفظ نسخة أمان من البيانات الحالية أولًا، ثم تُستبدل.

## الاختبارات

| الأمر | ماذا يختبر |
|---|---|
| `npm test` | الوحدات: المولّدات، صيغة النسخ الاحتياطية، التخزين… |
| `npm run build && npm run test:e2e` | المتصفح على البناء الثابت: كل الألعاب، السباق المقسوم، اللمس، الشاشات، النسخ والاستعادة، العمل دون إنترنت، جهاز بلا WebGL |
| `xvfb-run -a npm run test:desktop` (لينكس) أو `npm run test:desktop` (ويندوز) | Electron: البيانات بجانب البرنامج، الثبات بعد إعادة التشغيل، النسخ التلقائية واستعادتها، نقل النسخ بين الويب وويندوز، مجلد غير قابل للكتابة، السباق والألعاب ثلاثية الأبعاد |
| سير عمل GitHub | البرنامج المغلّف الحقيقي على ويندوز: تشغيل، تثبيت صامت، إلغاء تثبيت |

## قائمة الفحص على أجهزة ويندوز ١٠ و١١ الحقيقية

هذه لا يمكن أتمتتها من بيئة التطوير، وتحتاج جهاز المدرسة والسبورة.

**النسخة المحمولة (على ذاكرة USB):**
1. انسخ `HeroesWorld-Portable.exe` إلى الذاكرة وشغّله (مع تحذير SmartScreen أول مرة). تظهر شاشة «جارٍ التحضير» ثم التطبيق.
2. افصل الإنترنت، وتأكد أن كل شيء يعمل.
3. الإعدادات ← «النسخة المحمولة (USB)»، ومجلد البيانات على الذاكرة نفسها.
4. أنشئ لعبة، وأغلق البرنامج، ثم انقل الذاكرة إلى جهاز آخر وشغّله. يجب أن تكون اللعبة موجودة.
5. يجب أن يكون في `HeroesWorld-Data\backups` ملفات `heroes-world-auto-….json`.

**المثبّتة:**
1. شغّل `HeroesWorld-Setup.exe`، واختر المجلد، وتأكد من اختصار سطح المكتب «عالم الأبطال».
2. أنشئ لعبة وصدّر نسخة احتياطية (نافذة «حفظ باسم» من ويندوز).
3. ألغِ التثبيت من «الإعدادات ← التطبيقات» ثم ثبّته من جديد. يجب أن تبقى البيانات.

**السبورة الذكية وشاشات اللمس:**
1. F11 أو زر ملء الشاشة.
2. «سباق الأذكياء»: لمس الفريقين معًا (الأحمر يمينًا والأزرق يسارًا) بلا تداخل، والمؤقت المشترك يعمل.
3. السحب في جزيرة الأرقام والقطار، والبالونات (Phaser)، والألعاب ثلاثية الأبعاد (الصاروخ، الفضاء، المجسمات).
4. التكبير بإصبعين لا يكبّر الصفحة.

**الصوت:** المؤثرات تعمل دائمًا. النطق العربي يحتاج حزمة الكلام العربية في ويندوز (الإعدادات ← الوقت واللغة ← الكلام).

**النقل بين الإصدارات:** صدّر من الويب واستعد في المحمولة، ثم صدّر من المحمولة واستعد في المثبّتة.
