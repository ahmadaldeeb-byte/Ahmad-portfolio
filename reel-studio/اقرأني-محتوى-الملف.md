## تفتحه على جهازك
```bash
cd reel-studio
npm install
npm run studio        # Remotion Studio → Episodes/CameraHistory/CH01…CH10 و GimbalTiltReelVO
```
بدك Node 22. Blender اختياري (بس لتعديل المجسّمات).

## التصدير النهائي (بعد المراجعة)
```bash
bash series/camera-history/render-all.sh 01 02 03 04 05 06 07 08 09 10
```
→ `out/series/CHNN-<اسم>-FINAL-VOICE.mp4` بدقة 1080×1920.

نفس المحتوى موجود على GitHub بالفرع `claude/arabic-cutaway-explainer-919m4t` بمستودع `ahmad-portfolio`.
